# 🚀 Featured Projects  

## 🔹 Local RAG Assistant  
📚 Built a fully local **Retrieval-Augmented Generation system** using **ChromaDB, Ollama, Llama-3, FastAPI, and Docker**.  
🔐 Enabled private document Q&A with **zero external API calls**.  
⚙️ Added retrieval-confidence gating and fallback responses to reduce unsupported answers.  

## 🔹 MCP Agent Browser  
🌐 Developed a **Playwright-based LLM browser agent** that executes multi-step web automation using natural-language commands.  
🧠 Implemented session memory and tool orchestration for browsing workflows.  
🐳 Deployed as a Dockerized FastAPI service with agent-style planning.  

## 🔹 Explain The Model

📈 Built reusable visual analytics workflows for model debugging.
